# Stitch Payments for WooCommerce

**Stitch Payments for WooCommerce** is a standalone WooCommerce extension that lets your store accept credit and debit card payments through [Stitch Payments](https://www.stitchpayments.net/) and the CardPointe platform.

The plugin was developed by [MindK](https://www.mindk.com/) for merchants who want a professional, secure checkout experience on both **classic WooCommerce checkout** and **WooCommerce Blocks checkout**.

## Current release

**0.7.0** — Tested with WordPress 7.1.3 and WooCommerce 11.2.0. See the [Changelog](/docs/changelog). PHP was previously tested up to 8.5.1.

## What you get

- A WooCommerce payment gateway (`stitch`) with test and production credentials
- Hosted card number tokenization — card data stays off your server
- Guest checkout with a new card; saved payment methods for returning (logged-in) customers
- Charge immediately, or authorize now and capture later from the order screen
- Refunds, voids, subscription renewals, and WooCommerce Pre-Orders
- Level 2 / 3 data for commercial cards, and optional AVS / CVV checks
- Optional credit card surcharge, shown beside the card fields and added to the order as a fee line
- Admin settings with a **live checkout preview**
- Hooks and template overrides for customization

## Requirements

- WordPress 6.5+ (tested with 7.1.2)
- WooCommerce (active, tested with 11.1.2)
- PHP 7.4+ (tested up to 8.5.1)
- Store currency set to **USD** (the gateway is hidden at checkout for other currencies)
- Stitch / CardPointe merchant credentials
